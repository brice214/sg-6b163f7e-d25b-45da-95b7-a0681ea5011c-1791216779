# SPIDERHOSTER — Site Vitrine Premium

## Vision
Site vitrine moderne pour SPIDERHOSTER, hébergeur web professionnel africain. Présenter les services d'hébergement (Web, WordPress, VPS) et noms de domaine avec un design premium rivalisant avec les acteurs internationaux (Cloudflare, DigitalOcean, Vercel) tout en conservant une identité africaine forte. Aucune base de données, aucun dashboard — contenu géré directement dans les fichiers, boutons d'achat redirigeant vers plateforme externe.

Public: Entreprises africaines, startups, développeurs cherchant hébergement fiable au Gabon et en Afrique.

## Design
**Direction:** Infrastructure cloud africaine moderne — salle serveur tech à Libreville, interfaces CLI précises, connectivité réseau visualisée.

**Palette (extraite du logo SPIDERHOSTER):**
- `--primary: 214 100% 50%` (bleu tech du logo)
- `--accent: 25 95% 53%` (orange énergétique)
- `--background: 220 17% 97%` (blanc cassé froid)
- `--foreground: 220 13% 13%` (quasi-noir bleuté)
- `--muted: 220 13% 91%` (gris bleuté clair)
- `--card: 0 0% 100%` (blanc pur)
- `--border: 220 13% 88%` (bordures subtiles)

**Typographie:**
- Display: JetBrains Mono (600, 700) — précision technique, headers
- Body: Inter (400, 500, 600) — lisibilité moderne, texte courant
- Data: JetBrains Mono (400) — specs techniques, pricing

**Style:** Surfaces en profondeur (shadows, elevation), animations de flux réseau (dots connectés, lignes data), micro-interactions sur CTA, hero avec illustration serveurs/cloud/Afrique numérique. Score Lighthouse > 95.

## Features
**Pages principales:**
- Accueil: Hero + Services + Pourquoi SPIDERHOSTER + Offres + Domaines + Témoignages + Blog + FAQ
- Hébergement Web: Présentation + 3 forfaits (Starter/Business/Premium) + FAQ
- Hébergement WordPress: Optimisations + 3 forfaits + FAQ
- Hébergement VPS: Performance + Sécurité + 3 forfaits + FAQ
- Noms de Domaine: Recherche + Extensions + Tarifs + FAQ
- À propos: Histoire + Mission + Vision + Valeurs
- Blog: Liste articles statiques + catégories + pagination
- Contact: Formulaire (service externe) + coordonnées

- Header: Barre supérieure (contact/réseaux) + Menu sticky + Boutons Espace Client/Panneau (externes)
